# Плеер табулатур (тёмная тема, на всю ширину)

Плеер на базе [alphaTab](https://www.alphatab.net/): открывает файлы Guitar Pro (`.gp`, `.gp5`, `.gpx`), позволяет выбирать песню и инструмент, включать Mute/Solo, менять громкость, скорость и масштаб.

## Как добавить свои песни

Откройте `index.html` и найдите блок `SONGS`:

```js
var SONGS = [
  { title: 'Песня 1', url: 'https://ВАШ-БАКЕТ.хранилище.ru/song1.gp' },
  { title: 'Песня 2', url: 'https://ВАШ-БАКЕТ.хранилище.ru/song2.gp5' }
];
```

Замените `title` на название и `url` на прямую ссылку из S3.

## Вставка на Tilda

1. Добавьте блок **T123 (HTML-код)**.
2. Скопируйте из `index.html` всё между строками `НАЧАЛО` и `КОНЕЦ`.
3. Вставьте ссылки на свои файлы и опубликуйте страницу (в предпросмотре скрипты могут не работать).

## Требования к S3

- Файлы доступны по прямой публичной ссылке.
- В бакете включён CORS: источник — адрес вашего сайта, методы `GET` и `HEAD`, заголовки `*`.

## Свой сайт на GitHub Pages

Settings → Pages → Branch: `main` / root. Страница откроется по адресу `https://inciferm.github.io/tab-player/`.
